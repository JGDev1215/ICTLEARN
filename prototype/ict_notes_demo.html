Selected session

Date and session controls

The arrows skip dates without complete candles for the selected session. The calendar can select any day; weekends, holidays and gaps may have no observations. Asia belongs to the following trading date: Monday's Asia window starts Sunday at 20:00 ET. All windows use America/New_York and adjust for daylight saving time.

Gold carries forward the most recent elapsed, non-overlapping canonical session with observations. This is a chart comparator. An asterisk marks an incomplete prior range. Optional prior RTH is the latest elapsed RTH window with observations; its final chart close is not official settlement.

Purple marks a mechanically detected, three-candle gap for review. The example selects the earliest detected gap forming after the RTH open when that open is in view, otherwise after the session start. This selection is an illustration rule, not the notes' undefined “first-presented FVG” qualification. Only three consecutive, complete candles qualify, and the box starts after the third candle closes.

Rose measures the selected upper or lower wick. Midpoint lines are exact; displayed prices round to 0.25 points, with half ticks rounded up. Drawings are kept separately for each date/session during this visit.

Data boundaries

Source: the project's read-only NQ one-minute SQLite history. The chart defaults to complete 1-minute OHLC candles; 5-minute candles are aggregated from those same one-minute rows. Missing or incomplete source slots stay empty. The database includes a fixed Databento segment and a mutable Yahoo NQ=F continuation; this viewer keeps that source distinction visible and does not verify fixed-contract identity. No live feed, event context or SMT inputs are supplied.

Daily study loop

Jump to another date or session, then use Compare day to overlay a normalized close path from a second study day. Look for repeated timing, range interaction, displacement, FVG response and nearby reference confluence before recording expectation, delivery and invalidation.
